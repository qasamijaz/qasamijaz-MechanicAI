# Document index module

A minimal local, evidence-only index adapter. It reads `schema_version: 1` metadata generated by `modules.document_ingestion` and searches headings and candidate part numbers.

## Example

```bash
python scripts/search_documents.py documentation/local-index.json "oil pump" \
  --manufacturer Suzuki --model GSX-S1000F --year 2019 --market DK
```

`documentation/local-index.json` does **not** exist until a permitted local PDF has been processed.

## Contract
- Input: validated JSON metadata index and exact vehicle identity.
- Output: bounded candidate matches with original filename/hash, confidence gates, and `page: null`.
- Missing page citations and unverified fitment are explicit.
- No generated repair guidance, external API, network traffic, PDF redistribution, or Qdrant dependency.
- Tests: `python -m unittest discover -s tests -p 'test_*.py' -v`.

## Remaining work
This is metadata keyword search, not RAG or semantic retrieval. A page-aware, licensed-document extractor and human verification process must be implemented before using results to guide repairs. Integration with the browser UI is deliberately blocked until that gate.
