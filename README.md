# MechanicAI

Independent web-first prototype for voice-guided, source-grounded 3D maintenance instructions.

## Isolation

Completely separate from DeenRoutine: no shared code, database, credentials, infrastructure, or deployments.

## V1

- Local React + Vite web interface
- React Three Fiber interactive 3D viewer
- Open-source speech recognition evaluation
- Source-grounded Suzuki technical procedure support
- Verified component geometry; generated meshes are illustrative until checked

All technical specifications require verification against the exact motorcycle model and year.
