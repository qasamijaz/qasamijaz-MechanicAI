# MechanicAI V1 roadmap

1. Local 3D demo and voice command prototype (browser Web Speech API initially).
2. Import user-supplied GLB/GLTF and component IDs; add model validation and provenance.
3. Evaluate whisper.cpp or faster-whisper for local Danish STT.
4. Add manual ingestion with page-level citations and exact vehicle identification.
5. Compare GitHub/Hugging Face 3D-generation models on verified reference geometry, license and GPU needs.
6. Only after technical review: procedure steps and camera-assisted component identification.

**Safety gate:** generated meshes and inferred dimensions must never be presented as verified repair specifications.
